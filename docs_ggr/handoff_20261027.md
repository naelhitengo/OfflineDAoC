## Acquis (détails dans [carrieres-specialisations.md](carrieres-specialisations.md))

- « Career » = **deux notions** :
  - la **carrière d'une classe** : table `ClassXSpecialization` (`ClassID`, `SpecKeyName`, `LevelAcquired`), chargée par `SkillBase.LoadClassSpecializations()` (`SkillBase.cs:678`), lue par `GetSpecializationCareer(classID)` (`:2660`), qui ajoute les lignes `ClassID = 0` ;

- Une ligne de la carrière n'est pas forcément un `CareerSpecialization` (`Slash`, `Shields` restent entraînables).
- Le type d'une ligne vient de la colonne `Specialization.Implementation` ; `GetSpecialization` crée une nouvelle instance à chaque appel (constructeur à 4 arguments).
- `GamePlayer.LoadClassSpecializations` (≈ 9953) : carrière → cas Sluaghbinder → purge des lignes `Trainable || !AllowSave` absentes → ajout/retrait selon `LevelAcquired`. `GameBot.cs:3279` fait pareil.
- Clé `SpecKeyName` inconnue dans la carrière : ignorée **en silence** (`SkillBase.cs:2684`, `:2709`).

## À faire quand une base est disponible (copie, serveur arrêté, lecture seule)

```sql
SELECT Implementation, COUNT(*) FROM Specialization GROUP BY Implementation;
SELECT KeyName, Implementation FROM Specialization WHERE Implementation LIKE '%Career%';
SELECT c.ClassID, c.SpecKeyName, c.LevelAcquired FROM ClassXSpecialization c
  JOIN Specialization s ON s.KeyName = c.SpecKeyName WHERE s.Implementation LIKE '%WideCareer%';
SELECT ClassID, SpecKeyName, LevelAcquired FROM ClassXSpecialization WHERE ClassID = 0;
SELECT c.ClassID, c.SpecKeyName FROM ClassXSpecialization c
  LEFT JOIN Specialization s ON s.KeyName = c.SpecKeyName WHERE s.KeyName IS NULL;  -- orphelines
```
Confirmer les noms de colonnes avec `python docs_ggr/exemples_sqlite.py <db> schema Specialization`.
